# PKSMP.NET Team Fixers Application — Cloudflare Pages

This version keeps the same Team Fixers application design and works as a static Cloudflare Pages site.

## What changed
- No Node.js required for the online version.
- No SQLite or native C++ tools.
- Applications are sent to bonbonthegamer31@gmail.com through FormSubmit.
- The first submission may require confirming the email address with FormSubmit.

## Cloudflare Pages
Upload the contents of this folder to GitHub and connect the repository to Cloudflare Pages.

Build command: leave blank
Build output directory: `public`

If Cloudflare asks for a framework, choose no framework / static site.
